- [ ] GitHub repository is public
- [ ] Demo video uploaded
- [ ] Reply/quote-repost the Binance announcement
- [ ] Complete the official survey
- [ ] Verify deadline and eligibility immediately before submitting
- [ ] Do not expose `.env`, API keys, bearer tokens, cookies or screenshots containing secrets

## Suggested pitch

**AlphaGuard is an explainable AI crypto risk analyst built for Binance Agent OS.**

Instead of another black-box trading bot, AlphaGuard observes market conditions, evaluates portfolio concentration and volatility, generates explicit scenarios, and tells the user exactly what conditions would invalidate its thesis.

The agent is read-only by default, auditable, and designed so execution can sit behind human approval and least-privilege permissions.
